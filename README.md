# 🩺 AI Breast Cancer Detection System

[![Streamlit App](https://static.streamlit.io/badge_gradient.svg)](https://streamlit.io/)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An advanced, interactive machine learning application built with **Streamlit** to assist in the early screening and diagnostic risk assessment of breast cancer. The system utilizes a **Support Vector Machine (SVM)** classifier combined with **Explainable AI (SHAP)** and dynamic visualizations to provide highly transparent risk prediction.

---

## ✨ Key Features

- **🌐 Sleek Interactive Dashboard**: Customized dark theme with modern glassmorphism panels, glowing indicator states, and floating sidebars.
- **📊 Interactive EDA (Exploratory Data Analysis)**: Dynamic histograms, feature distribution graphs, and correlation heatmaps to explore tumor characteristics.
- **🤖 On-Demand Model Training**: Train the model in real-time, view training metrics, a confusion matrix heatmap, and a detailed classification report.
- **🔮 Live AI Prediction**: Predict tumor class (Malignant or Benign) based on 30 clinical sliders. Features an interactive AI Confidence gauge and probability breakdown.
- **🧠 Explainable AI (XAI)**: Identifies the top 5 clinical features most heavily influencing the model's prediction.
- **📄 Downloadable PDF Report**: Generate a printable clinical summary including diagnosis, risk assessment level, confidence metrics, top risk factors, recommendations, and model information.

## 🚀 Setup and Installation

Follow these steps to run the application locally on your computer:

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/BreastCancerApp.git
cd BreastCancerApp
```

### 2. Create and Activate a Virtual Environment
**On Windows:**
```powershell
python -m venv .venv
.venv\Scripts\activate
```
**On macOS/Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit Application
```bash
streamlit run app.py
```
The app will automatically open in your browser at `http://localhost:8501`.

## 🧪 Machine Learning Details

- **Algorithm**: Support Vector Machine (SVM) with a Radial Basis Function (RBF) kernel.
- **Dataset**: Breast Cancer Wisconsin (Diagnostic) Dataset.
- **Target Classes**: Malignant (`1`) vs. Benign (`0`).
- **Features Used**: 30 computed features from a digitized image of a fine needle aspirate (FNA) of a breast mass.
